# VICOM Billing System

VICOM WiFi Billing — Phase 1 foundation.

Kenyan ISP/WiFi billing platform for MikroTik providers. Built incrementally according to the VICOM Billing System specification.

Phase 1 foundation setup is being implemented first: Django, PostgreSQL, multi-tenancy, custom users, JWT authentication, tenant registration, Super Admin, ISP Admin, and the basic dashboard.
